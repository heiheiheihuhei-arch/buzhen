# 画阵

手指在沙盘上画兵阵，和敌军（同样是盾、枪、弓、骑）对打的灰盒原型。整个游戏就是一个文件 `index.html`。

## 怎么玩

下载（或 `git clone`）后，**双击 `index.html`** 用浏览器打开就能玩，不用装任何东西，不用联网。
（联网时标题会用「马善政」毛笔字体，断网时自动换成系统楷体。）

阵型存档记在浏览器本地，换电脑、换浏览器不会带过去。

## 测试（可选，开发用）

需要 macOS、Google Chrome、python3：

```bash
sh tools/run_bot.sh "draw=1&to=6"
```

- `tools/bot.js`：挂机机器人，每波把兵摆满、开战、选第一张卡，打印评级和战损比
- `tools/ui_test.js`：存阵 / 读阵 / 框选平移 / 换兵种 / 大波小波 的检查脚本（用法同上，换成这个脚本）
- `tools/cdp.py`：用无界面 Chrome 跑测试脚本的小工具

难度参数在 `index.html` 里搜 `const TUNE`：`p0` 第 1 波敌军兵力，`pG` 每波增加多少。
